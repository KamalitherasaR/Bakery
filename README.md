# 🍩 Joe & Emal Bakery

A beautiful and responsive bakery website created using **HTML, CSS, and JavaScript**. This project showcases bakery products, delicious treats, a photo gallery, and email-based ordering.

## 🌐 Live Website

**[Visit Joe & Emal Bakery](https://kamalitherasar.github.io/Bakery/)**

## ✨ Features

- Responsive bakery website design.
- Attractive homepage with bakery background.
- About section introducing the bakery.
- Menu section displaying bakery products and prices.
- Order Now buttons for individual menu items.
- Email integration using Gmail.
- Contact form for customer enquiries.
- Interactive gallery with image enlargement.
- Automatic copyright year update.
- Custom donut favicon 🍩.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- GitHub Pages

## 🚀 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/KamalitherasaR/Bakery.git
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser or use the Live Server extension.

## 📧 Email Integration

The website provides email-based ordering and contact functionality.

- Customers can click **Order Now** to prepare an email containing the selected product and price.
- Customers can submit the contact form to prepare an enquiry email.
- Email drafts open in Gmail, where customers can review and send their messages.
